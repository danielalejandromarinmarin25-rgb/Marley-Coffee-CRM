# Marley Conecta B2B — nueva versión UX/UI

Prototipo académico para Marley Coffee Chile. La aplicación anterior se conserva sin cambios en la raíz del repositorio.

## Abrir y compartir

1. Descarga el repositorio completo: Code → Download ZIP.
2. Descomprime el ZIP.
3. Abre `public/marley-conecta/index.html` en el navegador. Conserva app.js y style.css junto a index.html.

No requiere instalar dependencias. Si ejecutas el servidor de desarrollo de la aplicación original, la nueva versión está en `/marley-conecta/index.html`.

## Trabajar en equipo

Cada integrante usa su cuenta de GitHub. Los colaboradores pueden editar estos archivos desde una rama y proponer un pull request hacia main. No compartan contraseñas ni API keys.

- index.html: entrada de la aplicación.
- style.css: diseño responsive y colores.
- app.js: navegación, catálogo, carrito, pedidos, casos y vista ejecutiva.
- Prompt_Marley_Conecta.md: especificación de producto reutilizable para AI Studio.

## Probar

Agrega productos, revisa cantidades y envía una solicitud demo. Revisa el historial. Registra un caso técnico y entra en Vista ejecutiva · demo para responderlo. Vuelve al cliente y revisa el seguimiento.

## Límites

Datos y precios ficticios/referenciales. No se envían pedidos, pagos ni mensajes externos. Los datos se mantienen en memoria de esta página y desaparecen al recargar. No se comparten entre compañeros ni dispositivos. Las fotografías no se suben. El selector de ejecutivo es demostrativo, no autenticación.

Para producción: identidad y permisos por empresa/sucursal, persistencia central, CRM, logística, mensajería autorizada, validación de marca/catálogo y pruebas con clientes.
