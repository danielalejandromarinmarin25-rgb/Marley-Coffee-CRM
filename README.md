# Marley Coffee CRM

Repositorio de trabajo del proyecto B2B.

## Nueva versión: Marley Conecta B2B

La nueva propuesta UX/UI está en **[public/marley-conecta](public/marley-conecta)**. Incluye pedidos, ayuda técnica, consultas y vista ejecutiva de demostración.

**Para abrirla:** Code → Download ZIP → descomprimir → abrir `public/marley-conecta/index.html` en el navegador. No requiere instalaciones.

[Guía de uso y colaboración](public/marley-conecta/README.md) · [Prompt profesional](public/marley-conecta/Prompt_Marley_Conecta.md)

La aplicación anterior de React/Express se mantiene intacta en la raíz y en src. La nueva versión no reemplaza sus funciones de IA; es un prototipo independiente con datos de demostración.

Cada compañero debe trabajar desde su propia cuenta y proponer mejoras mediante ramas y pull requests. Los registros del prototipo no se sincronizan entre usuarios y se pierden al recargar.
